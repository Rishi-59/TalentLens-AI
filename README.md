# TalentLens AI

Production-ready AI Hiring Copilot built with Flask and LLMs for resume analysis, candidate screening, job matching, and recruiter workflows.

## Tech Stack

- Python
- Flask
- OpenAI API
- Pydantic
- pdfplumber
- Whisper
- OpenCV
